# Виправлення аудиту — робочий журнал

Стан: у роботі, 18.10.2026. **Не є підтвердженням готовності до релізу.** Після підтвердження тестового призначення БД застосовано 17 міграцій і розгорнуто 35 Edge Functions; frontend/Node backend потребують окремого deployment. У репозиторії були сотні попередніх змін — вони збережені.

Облік 41 початкової знахідки після F02: **38 мають основне локальне виправлення, 1 часткова (F18), 2 ще не виправлені (F06/F08)**. Залишок основної реалізації — **3 пункти**, окремо від staging/deployment verification. F14 рахується за початковим критерієм «атомарне збереження району»; раніше його статус був невиправдано розширений до всіх адмінських операцій. F27 має серверний audit для БД/Auth/Storage та журнал Stripe-операцій зі звіркою; staging і розбір виняткових pending випадків обліковуються окремо. Зелені тести не означають автоматичного закриття production-ризиків.

Актуальна перевірка 18.10 після виправлення завантаження статистики: **211 frontend / 312 security / 38 Edge tests**, lint, TypeScript, production build та dependency audit успішні. Деталі — [RPC-VISIBILITY.uk.md](RPC-VISIBILITY.uk.md), [USER-TIME-HARDENING.uk.md](USER-TIME-HARDENING.uk.md), [POSTGRES-UPGRADE.uk.md](POSTGRES-UPGRADE.uk.md), [BILLING-DELETION.uk.md](BILLING-DELETION.uk.md). Подальші записи з попередніми датами й кількістю пунктів є історією роботи.

Остання перевірка продовження географії/аудиту 17.10: `npm run check` успішний — lint, **198 frontend / 222 security**, TypeScript і production build. `npm run check:edge` — **38 tests**, dependency audit успішний. Додано 9 SQL geography, 1 handler delegation та 5 audit/auth regressions. Міграції `20261017053428_atomic_geography_admin_actions.sql` і `20261017125702_bind_admin_mutations_to_audit.sql` застосувати до deployment нового admin-geo-manage і всіх Edge, що імпортують `_shared/auth.ts`. Старі Edge без actor-header не отримують нового row-аудиту автоматично; необхідний redeploy і staging перевірка PostgREST зі справжніми API keys. SQL-тести ізольовані (PGlite); живу БД лише читали для перевірки типів колонок та audit constraints. Подальший стан deployment — ../../DATABASE-ROLLOUT.uk.md.

Остання перевірка F20/F21: `npm run check` — lint, **198 frontend / 207 security**, TypeScript і production build успішні; `npm run check:edge` — **38 tests**, dependency audit успішний. Production не змінено; readonly інвентаризація підтвердила формати фото. Нових UI-ключів перекладів немає. Для розгортання: спочатку новий `get-district-photo` з `verify_jwt=false` і сумісні Edge endpoints, потім frontend (новий search totals контракт), потім приватизація bucket міграцією. Старі клієнти з прямими public URL потребують оновлення. Перевірити старі public URL/CDN, видимий/прихований район і місто, адмінський preview та пошук у браузері. Уже видані public signed URLs живуть до 60 с; адмінські — до 15 хв. Раніше завантажені копії файлів відкликати неможливо.

## Очищення та синхронізація 18.10

Прибрано 76 тимчасових файлів (логи, сирі знімки БД, застарілий Swagger, одноразові скрипти й дублікати звітів); історичний журнал скорочено до актуальної таблиці. Regression tests і migration history збережено. Новий check-security автоматично знаходить ті самі 45 suite-файлів; вивід --list порівняно зі старим списком без відмінностей. У statsApi винесено спільний запис активності без зміни payload/умов авторизації. Knip не виявив невикористаних файлів чи залежностей. Фінальна збірка перевіряється командами README; актуальні логи пишуться лише до ігнорованої logs/.

Після прямого підтвердження користувачем тестового призначення поточної БД застосовано 17 міграцій, redeploy 35 Edge, перегенеровано типи. Remote dry-run: upToDate=true. Read-only deployed smoke: 14 passed, 1 skipped. Деталі й залишок — [DATABASE-ROLLOUT.uk.md](../../DATABASE-ROLLOUT.uk.md). F06/F08/F18 не вважати автоматично закритими.
