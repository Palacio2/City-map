# City-map: поточний стан

Оновлено 18.10.2026. Єдиний актуальний перелік знахідок — [журнал виправлень](audit/2026-10-15/REMEDIATION.uk.md), застосування БД/Edge — [стан синхронізації](DATABASE-ROLLOUT.uk.md). Цей файл більше не дублює історичний покроковий журнал.

## Виконано

- Основні локальні виправлення 38 із 41 початкової знахідки, regression tests і перевірки build/lint.
- 17 нових міграцій застосовано до поточної БД, яку користувач підтвердив як тестову. Незастосованих міграцій немає.
- 35 Edge Functions розгорнуто; public filters і відмови анонімному доступу перевірено read-only smoke.
- Збережено поточні runbooks, тести й історію міграцій; застарілі логи, знімки та одноразові скрипти видалено.

## Залишилось перед релізом

- F06: повний baseline та перевірене відновлення; Docker поки відкладений користувачем.
- F08: оновлення PostgreSQL; окремо перевірити leaked-password protection та решту platform advisors.
- F18: ключі й домен CAPTCHA; без них анонімна форма звернень закрита.
- Оновлення frontend і Node backend на хостингу, authenticated/browser/worker/concurrency сценарії.
- Перевірка Stripe webhook і reconciliation історичних підписок/промокодів: попередня перевірка 14.10 виявила disabled webhook і розбіжності Stripe/БД. Це не усувається самим deployment Edge. Стан потрібно перевірити заново; реальні Stripe-об’єкти не змінювались під час очищення/синхронізації.
- Визначити строк зберігання історії активності. Поточні серверні квоти обмежують її ріст, але не виконують retention.

Не трактувати успішні локальні тести або міграції як завершену перевірку реальних платежів чи готовність production.
